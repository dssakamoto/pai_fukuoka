## AC-001: [FR-001] SceneGeometry を XML から読む 🔵

**関連**: FR-001, US-003

### Given
- `assets/scene_pickplace.xml` に箱・ブロックの名前付き geom がある

### When
- `SceneGeometry` を読み込む

### Then
- 箱の内寸・縁の高さ・床面高さ・ブロック寸法が XML の値と一致する

### テストチェックリスト
- [ ] **正常系**: 読み込んだ値が MuJoCo モデルの geom size/pos と一致 🔵
- [ ] **異常系**: 必要な名前の geom が無い XML では `ValueError` (欠けた名前を含むメッセージ) 🟡
- [ ] **境界値**: geom が 1 つ欠けただけでも検出する 🟡

## AC-011: [FR-011] 箱の Fixed / UniformXY 切替 🔵

**関連**: FR-011, US-001

### Given
- `ScenarioSpec()` (既定) と `ScenarioSpec(box=UniformXY(...))`

### When
- それぞれで `sample_scenario` を呼ぶ

### Then
- 既定は `Fixed` で箱位置が seed によらず一定。`UniformXY` は指定範囲内で seed ごとに箱 xy が変わる (yaw は固定)

### テストチェックリスト
- [ ] **正常系**: 既定で箱位置が全 seed 一致 🔵
- [ ] **正常系**: UniformXY で範囲内かつ複数の異なる値 🔵
- [ ] **異常系**: 範囲の下限 > 上限は `ValueError` 🟡
- [ ] **境界値**: 範囲幅 0 は Fixed と同じ位置 🟡
