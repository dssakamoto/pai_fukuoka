# プロバイダ別の評価と比較表

## 条件

- 試行数: 20 (プロバイダごと)
- シード: 0〜19 (試行 i は 0 + i)。全プロバイダで同じ
- 対象の色: red, blue, green (この順に回す)
- 指示: `put the {colour} block into the box` ({colour} を色名に置き換える)
- 成功率の基準: 70% 以上 (暫定目標)

## 注記

- 検出誤差 = VLM の出力から算出した 3 次元位置 (ブロック中心の推定) と、シミュレーション上の真のブロック中心の距離 [mm] (AC-05)。推定が出なかった試行 (VLM 失敗など) は平均・中央値に入れない。
- 検出誤差には、枠が完全でも出る深度方式の偏り (約 6〜9 mm。斜めのカメラで枠の中心画素の深度が側面に当たる) を含む。
- 参考 = oracle: 真の配置から作った枠 (実際の VLM ではない)。パイプラインの上限を見るための行。
- トークン = API を呼んだ試行の入力・出力トークンの累計 (キャッシュから返した分は含まない)。料金 = 入力 x 入力単価 + 出力 x 出力単価 (単価は各社の料金表)。
- 未評価 = API キーがない、またはクライアント未実装。評価していない (成功率 0% ではない)。中断 = 評価の途中で想定外の例外。
