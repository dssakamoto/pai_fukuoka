# TASK-0011 到達性調査(姿勢制約付き IK)

**作成日**: 2026-10-20
**対象**: `assets/scene_pickplace.xml`(`PICKPLACE_SCENE_PATH`)、site `gripperframe`
**目的**: IK の要件(ピッチ候補・許容角)、TASK-0012 の軌道、TASK-0009 の確認、シーン配置の判断材料を得る。
**結論(先に要約)**:

1. **接近軸は `gripperframe` の +x 軸**。ノート(note.md 6.2)が仮定した「-z 軸」は誤り。「真下を向く」= site の +x 軸が世界の -z と一致すること。
2. `gripperframe` は**固定顎の先端**にあり、両顎の中央(把持中心)ではない。顎は site の z 方向に閉じ、把持中心は site +z 方向に約 15 mm(3 cm ブロックの場合)ずれる。
3. 接近軸を正しく取ると、**把持高さ z=0.015 では作業範囲の 78%(x ≤ 0.30 の全点)が真下 0° で届き、全点が 15° 以下で届く**。予備調査の「把持高さで真下はほぼ不可」は、軸の取り違えによる誤りだった。
4. 真下を妨げる主因は **wrist_flex の上限(+1.658 rad)**。高い位置ほど真下が難しく、**接近高さ z=0.095(把持点の 8 cm 上)では真下 0° が全点で不可**。5〜30° 傾ければ全点で届く。
5. **シーンの変更は不要**(推奨)。作業範囲・箱の位置・ブロック寸法はこのままでよい。ピッチ候補を 0〜30° の範囲で細かく持てば足りる。

### 1.2 ソルバ

- 変数: 腕の 5 関節(shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll)。gripper は除外(0 のまま)。
- 専用の `MjData`。FK は `mj_kinematics` + `mj_comPos`、ヤコビアンは `mj_jacSite(gripperframe)`。
- DLS: `dq = Jᵀ (J Jᵀ + λ² I)⁻¹ e`、λ = 0.01、1 ステップの更新量の上限 0.2 rad、反復 300 回、毎反復 `jnt_range` でクリップ。
- 姿勢の残差の重み W = 0.1(向きの誤差 1 rad を位置 10 cm 相当とみなす)。
- 傾き(ピッチ)t の定義: 接近軸 a(site +x)と世界 (0,0,-1) のなす角。
- **方式 A**(接近方向を 2 自由度で拘束): 目標方向 `a_des = cos t·(0,0,-1) + sin t·r̂`。r̂ は shoulder_pan 軸 (0.0388, 0) から目標への水平単位ベクトル(t>0 で指先が外向き)。残差 `a_des − a`、ヤコビアン `−[a]× J_rot`。
- **方式 B**(設計 4.5 の文言どおり「下向き成分のみ」を拘束): 残差 `−cos t − a_z` の 1 行。傾きの向き(外向き・内向き)は拘束しない。
- 成功判定: 位置誤差 < 1 mm かつ |傾き − t| < 1°(方式 A は a と a_des のなす角 < 1°)、可動域内(クリップ済み)。
- シード: 固定 6 個 + 乱数 14 個(`default_rng(0)`)の計 20 個。各シードの shoulder_pan は目標の方位角に置き換える。いずれかで成功すれば「到達可」。**到達可の判定は下限値**(見つからなかった点が本当に不可とは限らない。2.5 節)。

- 拘束が緩い方式 B の方が、方式 A より 0° の到達数が少ない(48 < 63)。これは**到達性ではなく DLS の収束の差**。x 0.25〜0.30 の真下は wrist_flex がほぼ上限(余裕 0〜0.01 rad)になる境界の解で、クリップ付き DLS が止まりやすい。

## 3. 推奨

### (i) IK のピッチ許容

- ピッチ候補: **(0, 10, 20, 30, 45, 60)°**、各候補の許容 **±5°**、真下に近い順に試す。±5° で 0〜35° と 40〜65° が切れ目なく覆われる。
- 作業範囲で必要な傾きは、把持で 0〜15°(方式 A)/0〜30°(方式 B・roll 固定)、接近で 5〜30°、箱で 0〜30°。**通常は 30° 以下で足り、45°・60° は予備。**
- 境界付近のシード依存性を下げるため、シードは「呼び出し側の seed + 固定の追加シード(wrist_flex を上限付近に置いたものを含む)」とする。

### (ii) シーンのパラメータ

- **変更不要(推奨)**。作業範囲 x 0.15〜0.35 は、傾き 30° 以下で把持・接近の両方が全点で届く。箱 (0.20, 0.19) も届く。ブロック寸法(3 cm)は到達性に影響しない。
- 真下(0°)の把持を全点で保証したい場合だけ、作業範囲の x を 0.10〜0.30 に寄せる案がある(ユーザー判断。ik-requirements.md の未決事項 D1)。

### (iii) 接近の高さと方向

- 接近の高さ 8 cm は維持してよい(推奨)。ただし**接近点で 5〜30° 傾く**ため、接近点と把持点で傾きが変わる。TASK-0012 は、接近点と把持点を**同じピッチ**で解く(両方が届く最小のピッチを選ぶ)ことを推奨する。そうすれば下降が接近軸に沿った移動に近くなる。
- 接近の高さを 4〜6 cm に下げても、x = 0.35 列は 0° にならない。下げる利点は小さい(未決事項 D2)。
- `gripperframe` は把持中心ではない(2.1 節)。TASK-0012 は目標を把持中心に合わせるオフセット(site 座標で約 (−5〜−10, 0, +15) mm、要実測)を扱う必要がある。

## 4. 制約と限界

- IK は衝突を見ていない。傾いた姿勢でブロック・箱・土台と干渉するかは、TASK-0012/0013 のシミュレーションで確認する。床へのめり込みは、最小傾きの解(gripper = 0)では見られなかった。
- 「到達不可」の判定は、20 シードで見つからなかったという意味(下限値)。境界の点(把持の x = 0.25〜0.30 の 0°)はシード次第で結果が変わる。
- 傾きの向きは方式 A では外向き(指先が土台から離れる向き)に限った。y = 0 では内向きの傾きは x ≤ 0.30 でのみ届き、外向きより有利なのは土台の真横(x ≤ 0.075)だけだった(作業範囲外)。
- ノート(note.md 0 節)の予備調査の表は、接近軸を site −z として計算したもので、本調査で置き換える。
