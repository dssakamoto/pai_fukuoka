要件は `requirements.md`、設計は `design.md` を参照。日程は仮(提出期限が未確認)。
各タスクは約半日〜1日の粒度。純粋ロジックは、テストを先に書く(RED → GREEN → REFACTOR)。

凡例: 依存 = 先に終わらせるタスク / 要件 = 関連する要件 ID / 完了条件 = 確認できる状態
