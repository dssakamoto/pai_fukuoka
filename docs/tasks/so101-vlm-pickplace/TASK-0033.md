## 実装詳細

### 1. macOS では udev が使えない 🔵

**信頼性**: 🔵 *ユーザヒアリング(2026-10-18)より*

実機の PC はこの Mac。udev は Linux の機能なので、別の方法にする。

**実装ファイル**: `docs/notes/real-setup.md`

### 2. シリアル番号でポートを探す 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

pyserial のポート一覧からシリアル番号で `/dev/cu.*` を見つける。

**実装ファイル**: `src/so101_vlm/robot/ports.py`

### 3. 設定ファイル 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

`configs/real.yaml` にポート名ではなくシリアル番号を書く。

**実装ファイル**: `configs/real.yaml`

### 4. カメラの特定 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

番号は変わることがあるので、起動時に名前や解像度で確認する。

**実装ファイル**: `src/so101_vlm/robot/ports.py`

### 5. 要件定義書の更新 🔵

**信頼性**: 🔵 *ユーザヒアリング(2026-10-18)より*

NFR-V2-03 の「udev」を、macOS ではシリアル番号による特定に読み替える旨を requirements.md に追記する。

**実装ファイル**: `docs/requirements.md`
