## タスク概要

関節指令を、可動域でクリップし、速度上限で制限し、作業範囲の外の目標を拒否する。状態が途絶えたら停止する判定も作る。すべて純粋関数にする。

**信頼性**: 🔵 *設計文書 design.md より*

**実装ファイル**: `src/so101_vlm/safety/limits.py`

### 3. 作業範囲の外の拒否 🔵

**信頼性**: 🔵 *設計文書 design.md より*

**実装ファイル**: `src/so101_vlm/safety/limits.py`

### 4. 状態途絶の検知 🔵

**信頼性**: 🔵 *設計文書 design.md より*

**実装ファイル**: `src/so101_vlm/safety/limits.py`

### 5. 入力を書き換えない 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*
