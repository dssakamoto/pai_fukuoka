## タスク概要

手先 `gripperframe` を目標位置に置く関節角を、減衰最小二乗法(DLS)で求める。5 自由度なので、手先を下向きに近づける姿勢を弱く拘束し、ピッチの候補を順に試す。

## 実装詳細

### 1. DLS による反復 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`mj_jacSite` でヤコビアンを求め、DLS で更新する(design.md 4.5)。

**実装ファイル**: `src/so101_vlm/policy/ik.py`

### 2. 姿勢の弱い拘束とピッチ候補 🔵

**信頼性**: 🔵 *設計文書 design.md より*

手先の下向き成分の重みを下げて拘束し、真下から斜めまでの候補を試す。

> **訂正済み(2026-10-20)**: 候補と許容を確定した(`docs/implements/so101-vlm-pickplace/TASK-0011/ik-requirements.md` 3.1 節、`reachability-survey.md` 3 節)。ノートの仮の候補(0°、15°、30°、45°、60°)と仮の許容は使わない。
> - 接近軸 = `gripperframe` の +x 軸(指の向き)。ピッチ = 接近軸と世界 (0, 0, −1) のなす角
> - ピッチ候補 `PITCH_CANDIDATES_DEG = (0, 10, 20, 30, 45, 60)`°、各候補の許容 ±5°、真下に近い順(指定順)に試し、最初に収束したものを採用
> - 解く変数は shoulder_pan・shoulder_lift・elbow_flex・wrist_flex の 4 関節。wrist_roll と gripper は seed の値をそのまま返す

**実装ファイル**: `src/so101_vlm/policy/ik.py`

### 3. 可動域とエラー 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`ctrlrange` でクリップし、収束しなければ `IkError`(FR-06)。

**実装ファイル**: `src/so101_vlm/policy/ik.py`

### 4. シミュレーション本体を変えない 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

IK 用に `MjData` を別に持ち、実行中のシミュレーションの状態を書き換えない。

**実装ファイル**: `src/so101_vlm/policy/ik.py`
