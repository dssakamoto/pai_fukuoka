## 実装詳細

### 1. pyproject.toml の作成 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

依存は mujoco、numpy、pyyaml、pytest、pytest-cov から始める。Python は 3.12 に固定する(この Mac の標準は 3.14 で、MuJoCo や LeRobot の対応版が限られる可能性があるため。実装時に各パッケージの対応版を確認する)。

**実装ファイル**: `pyproject.toml`

### 2. ディレクトリ構成 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`src/so101_vlm/` 以下に robot、vlm、perception、policy、safety、eval、record、nodes を作り、`configs/`、`assets/`、`scripts/`、`tests/` を用意する(design.md 6章)。

**実装ファイル**: `src/so101_vlm/__init__.py`

### 3. 秘密情報の扱い 🔵

**信頼性**: 🔵 *要件定義書 requirements.md より*

API キーは環境変数から読む。`.env.example` には変数名だけを書き、値は書かない(NFR-03)。

**実装ファイル**: `.env.example`

### 4. テストとカバレッジの設定 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

**実装ファイル**: `pyproject.toml`
