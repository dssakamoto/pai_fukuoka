## 実装詳細

### 1. 内部パラメータの計算 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

画角 `fovy` と画像サイズから `fy = (h/2) / tan(fovy/2)` などで求める。

**実装ファイル**: `src/so101_vlm/perception/calibration.py`

### 2. 外部パラメータの計算 🔵

**信頼性**: 🔵 *設計文書 design.md より*

カメラと `baseframe` の姿勢から `T_base_cam` を作る(design.md 4.4)。

**実装ファイル**: `src/so101_vlm/perception/calibration.py`

### 3. 設定への書き出し 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`configs/calibration.yaml`。実機では計測値で置き換える。

**実装ファイル**: `configs/calibration.yaml`
