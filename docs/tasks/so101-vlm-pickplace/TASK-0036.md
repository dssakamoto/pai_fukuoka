## 実装詳細

### 1. 外部パラメータの計測 🔵

**信頼性**: 🔵 *設計文書 design.md より*

チェッカーボード、またはロボットの手先を既知の位置に動かして求める(design.md 8章)。

**実装ファイル**: `scripts/calibrate_real.py`

### 2. 内部パラメータ 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

OpenCV のカメラキャリブレーションで求める。

**実装ファイル**: `scripts/calibrate_real.py`

### 3. 深度の扱い 🔴

**信頼性**: 🔴 *資料にない推測。実装時に確認が必要*

設計は深度カメラを前提にしているが、実機カメラが深度を取れるかは未確認(未決事項)。RGB のみの場合は、作業台の高さが既知であることを使って 3 次元位置を求める方式にする。

**実装ファイル**: `src/so101_vlm/perception/projection.py`
