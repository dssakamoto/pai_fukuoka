MuJoCo のビューアで SO-101 を表示し、6 つのアクチュエータに位置指令を与えて各関節が動くことを確かめる。関節の順序を定数として固定する。

## 実装詳細

### 1. 確認スクリプト 🔵

**信頼性**: 🔵 *既存タスク一覧 tasks.md より*

各アクチュエータに正弦波の位置指令を与える。

**実装ファイル**: `scripts/view_so101.py`

### 2. macOS でのビューア起動 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

macOS ではパッシブビューアの起動に `mjpython` が必要な場合がある。実装時に MuJoCo の公式ドキュメントで確認する。

**実装ファイル**: `scripts/view_so101.py`

### 3. 関節順の固定 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`JOINT_NAMES` を `robot/base.py` に置き、sim と実機で同じ順序を使う(design.md 4.1)。

**実装ファイル**: `src/so101_vlm/robot/base.py`

### 4. オフスクリーン描画で動画を出力 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

`mujoco.Renderer` で描画し、mp4 に保存する。

**実装ファイル**: `scripts/view_so101.py`
