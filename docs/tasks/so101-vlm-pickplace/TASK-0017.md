## 実装詳細

### 1. データ型 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`Detection(label, bbox_px, confidence)`、`PlanResult(pick, place)`。どちらも frozen(design.md 4.3)。

**実装ファイル**: `src/so101_vlm/vlm/schema.py`

### 2. 座標の変換 🔵

**信頼性**: 🔵 *設計文書 design.md より*

絶対ピクセル、0〜1000 の正規化、`[y, x, y, x]` の順などをピクセルに直す。

**実装ファイル**: `src/so101_vlm/vlm/schema.py`

```python
def from_normalized_yxyx(box, width, height):
    y1, x1, y2, x2 = box
    return (round(x1 / 1000 * width), round(y1 / 1000 * height),
            round(x2 / 1000 * width), round(y2 / 1000 * height))
```

### 3. エラー 🔵

**信頼性**: 🔵 *要件定義書 requirements.md より*

JSON 不正と対象なしは `PlanError`。この場合、ロボットは動かさない(FR-03)。

**実装ファイル**: `src/so101_vlm/vlm/schema.py`

### 4. 範囲外のクリップ 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

画像の外にはみ出た座標は、画像の範囲に収める。

**実装ファイル**: `src/so101_vlm/vlm/schema.py`
