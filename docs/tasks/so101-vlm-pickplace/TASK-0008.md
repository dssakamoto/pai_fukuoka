## タスク概要

バウンディングボックスと深度から、カメラ座標、さらにロボット座標の 3 次元位置を計算する純粋関数を作る。

## 依存タスク

- **後続タスク**: [TASK-0009: sim 用キャリブレーションの自動生成](TASK-0009.md)

## 完了条件

- [x] 投影と逆投影の往復誤差が 1mm 以下
- [x] 枠の中の深度は中央値を使う
- [x] 不正な深度でエラーになる

---

## 実装詳細

### 1. カメラ座標への変換 🔵

**信頼性**: 🔵 *設計文書 design.md より*

`pixel_to_camera(u, v, depth, K)`。内部パラメータ `fx, fy, cx, cy` を使う(design.md 4.4)。

**実装ファイル**: `src/so101_vlm/perception/projection.py`

### 2. ロボット座標への変換 🔵

**信頼性**: 🔵 *設計文書 design.md より*

同次変換 `T_base_cam` を掛ける(design.md 4.4)。

**実装ファイル**: `src/so101_vlm/perception/projection.py`

### 3. 深度の中央値 🔵

**信頼性**: 🔵 *設計文書 design.md より*

枠の中の有効な深度の中央値で、外れ値の影響を減らす。

**実装ファイル**: `src/so101_vlm/perception/projection.py`

### 4. MuJoCo のカメラ座標系 🟡

**信頼性**: 🟡 *要件定義書・設計文書から妥当な推測*

MuJoCo のカメラは -z 方向を向く。OpenCV の慣習(+z が前)との違いを変換で吸収する。実装時に確認する。

**実装ファイル**: `src/so101_vlm/perception/projection.py`
