## タスク概要

`ScenarioSpec.box = UniformXY(...)` で、到達可能領域の内側に箱の外周(内寸 + 壁)が収まる位置を、シードから決定的に生成する。ブロックにも同じ領域判定を入れるが、既定ではブロックの乱数は変わらない(FR-010, 011, 103, 104)。

- **後続タスク**: [SGT-012: 箱位置の掃引(3x3 格子 x oracle)スクリプトを追加する](SGT-012.md), [SGT-013: SCENE_SPEC の箱位置・作業範囲を削除し、再現性を最終確認する](SGT-013.md)

## 完了条件

- [ ] seed 0〜99 で、既定の領域がブロック領域を覆い、`UniformXY` のブロック配置が `Fixed` と完全に同じ(G1 (a) の保証)
- [ ] `UniformXY` で生成した箱の外周がすべて領域内、箱とブロックの間隔が `min_gap` 以上
- [ ] 同じ seed で 2 回生成すると同じ(決定的)、seed が違えば箱位置が変わる
- [ ] 領域が狭すぎて上限に達する設定で、試行回数を含む `ValueError`
- [ ] 箱を乱数で動かした Scenario 20 件に `apply_scenario` → `OracleVlm` を通し、すべて IK の計画失敗にならない
- [ ] 乱数は箱を最後に引く(`UniformXY` でもブロックの列が `Fixed` と一致することの回帰)
