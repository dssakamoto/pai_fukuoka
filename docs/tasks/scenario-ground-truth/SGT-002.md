## タスク概要

`policy/` と `perception/` が `eval/` および `scene_spec` を(直接・推移とも)import していないことを、`ast` で import を走査するテストで保証する(FR-106, FR-401, US-005)。

## 依存タスク

- **前提タスク**: [SGT-001: 検証関数を中立モジュールへ移設する](SGT-001.md)
- **後続タスク**: なし

## 完了条件

- [ ] 実リポジトリで policy / perception が `so101_vlm.eval` と `so101_vlm.eval.scene_spec` を(推移込みで)import していない
- [ ] `tmp_path` に作った「policy が eval を import する」合成パッケージでテストが失敗する(違反を検出する)
- [ ] `from . import x` / `from .. import y` の相対 import も違反として検出する
- [ ] `if TYPE_CHECKING:` 内の import も検出する(型の上でも依存させない方針)
- [ ] ファイルは `read_text(encoding="utf-8")` で読み、Windows の改行に依存しない
