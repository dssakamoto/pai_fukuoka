## タスク概要

`configs/motion.yaml` の `obstacle_geoms` の手書き列挙をやめ、モデルから障害物 geom を自動収集する。箱を動かしても、箱の種類を増やしても、安全側のコードは変わらない(FR-008)。

## 完了条件

- [ ] `collect_obstacle_geoms(model)` の集合が、現行 `obstacle_geoms` の 6 件と一致する
- [ ] ロボットの geom(group 3 を含む)とブロック(freejoint)は含まれない
- [ ] 箱を動かした(`body_pos` 変更)モデルでも、同じ名前の集合を返す
- [ ] 箱の geom を 1 つ増やした合成モデルで、増えた geom が含まれる
- [ ] `obstacle_geoms` が yaml に無い(空)とき自動収集に切り替わり、あるときは従来どおりその値を使う(移行期間)
- [ ] 既存の `policy/test_trajectory_config.py` と `test_ik_policy.py` が通る
