## タスク概要

xy 格子の各点で IK を解いて到達可能領域を一度だけ計算し、`configs/reachable.yaml` に保存する。実行時とテストは保存済みの結果を読むだけにする(FR-009)。

## 完了条件

- [ ] 保存済み yaml を読むと、`contains_xy` が既知の到達可能点(例: 現行の箱の位置 (0.20, 0.19))で True
- [ ] 領域の外(例: ロボットの付け根に近すぎる点・遠すぎる点)で False
- [ ] `bbox()` が mask の True の範囲と一致する
- [ ] 不正な yaml(行長が不揃い・0/1 以外)で `ValueError`
- [ ] 保存済み領域の bbox と `configs/motion.yaml` の `workspace` の食い違いを検知する整合テスト(G4: 自動生成はせず、値を残して検知する案を暫定採用・未確認)
- [ ] 保存済み領域が、ブロックの既定の作業範囲(x 0.15〜0.35, y −0.10〜0.10)を覆う(SGT-010 の前提)
