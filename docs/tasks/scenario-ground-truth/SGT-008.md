## タスク概要

方策に渡す情報を `Observation`(RGB・深度・指示・関節角のみ)に限定し、評価は差し替え可能な `Evaluator` Protocol にする。sim 実装 `SimEvaluator` までを対象とし、実機側は別 plan(FR-004, FR-007, FR-402)。

- **後続タスク**: なし

## 完了条件

- [ ] `Observation(q=..., timestamp=...)` だけで従来どおり作れる(IkPolicy が通る)
- [ ] `rgb` / `depth` を渡すと readonly 配列になり、書き込むと `ValueError`
- [ ] `Observation` に真値(GroundTruth / Scenario)のフィールドが無い(`dataclasses.fields` で検査)
- [ ] `SimEvaluator.evaluate("red")` が、箱に入れたブロックで成功、箱の外で `OUTSIDE_INNER`
- [ ] 箱を動かした `PlaceRegion` で `SimEvaluator` が追従する
- [ ] 任意のスタブ実装が `Evaluator` Protocol を満たす(`isinstance` ではなく型検査相当の呼び出しで確認)
