## タスク概要

ブロックと箱の配置を `Scenario` として表し、`sample_scenario(seed, spec)` で生成する。`box=Fixed` の既定では、同じ seed で既存の `sample_layout` と同じブロック配置になる(FR-002, 010, 011, 101, 201)。

## 依存タスク

- **前提タスク**: [SGT-003: SceneGeometry と PlaceRegion を XML から読めるようにする](SGT-003.md)
- **後続タスク**: [SGT-006: apply_scenario でシミュレーションに配置を反映する](SGT-006.md), [SGT-010: 箱位置の UniformXY 生成と到達可能性による棄却を実装する](SGT-010.md)

## 完了条件

- [ ] seed 0〜99 で `sample_scenario(seed).blocks == tuple(sample_layout(seed, ...))`(乱数の消費順序が変わっていない)
- [ ] `Fixed()` の `box_xy` が `(0.20, 0.19)`、`Fixed(xy=(0.25, 0.15))` ならそのとおり
- [ ] 同じ seed で 2 回呼ぶと等しい(`Scenario` が frozen で比較可能)
- [ ] 不正な seed(負・bool)で `ValueError`(副作用の前に)
- [ ] `Scenario.place_region(g)` が箱の `center_xy` と形状から作られる
- [ ] 既存の `tests/eval/test_layout.py` が無変更で通る

## インターフェース

```python
# src/so101_vlm/eval/scenario.py (新規)
@dataclass(frozen=True)
class Fixed:      xy: tuple[float, float] | None = None       # 🔵 None なら geometry.box_default_xy
@dataclass(frozen=True)
class UniformXY:  region: "ReachableRegion | None" = None; margin: float = 0.0   # 🟡 本タスクでは型だけ。生成はSGT-010
BoxSpec = Fixed | UniformXY
@dataclass(frozen=True)
class ScenarioSpec:                                           # 🔵 既定は configs/eval.yaml の placement と一致
    n_blocks: int = 3; area: float = 0.20; min_gap: float = 0.05; max_attempts: int = 10_000
    box: BoxSpec = Fixed()
@dataclass(frozen=True)
class Scenario:
    seed: int; blocks: tuple[tuple[float, float], ...]; box_xy: tuple[float, float]   # 🔵 tuple のみ(ndarray を持たない)
    def place_region(self, g: SceneGeometry) -> PlaceRegion: ...
def sample_scenario(seed: int, spec: ScenarioSpec = ScenarioSpec(), *, geometry=None, reachable=None) -> Scenario: ...  # 🔵
```

## 実装メモ

- 参照すべき既存コード: `src/so101_vlm/eval/layout.py:70-80`(`default_rng(seed)` から候補ごとに x, y の順に uniform)。
- 実装のヒント: 本体を `_sample_points(rng, ...)` に抽出し、`sample_layout` と `sample_scenario` が共有する。**ブロック → 箱の順**で同じ rng を使う(箱は最後に引く)。`Fixed` のときは乱数を 1 回も消費しないので、既存の seed と完全に同じになる(CON-004)。
- 注意事項: `sample_layout` / `place_blocks` の公開 API は変えない。
- 要件: FR-002, FR-010, FR-011, FR-101, FR-201, FR-404
