## Coding Conventions

### Naming

| Target | Convention | Example |
|--------|-----------|---------|
| Variables/Functions | snake_case | `sample_layout`, `judge_in_box` |
| Classes | PascalCase (frozen dataclass 多用) | `SceneSpec`, `JudgeResult` |
| Constants | UPPER_SNAKE | `SCENE_SPEC`, `COLOUR_TO_BODY` |
| Files | snake_case | `scene_spec.py` |
| Enum | `str, Enum` で小文字 snake の値 | `JudgeReason.ABOVE_RIM` |

### Error Handling
- 入力検証は早期に `ValueError`。副作用 (SimRobot 作成など) の前に行う 🟡
- ドメイン別の例外 (`IkError`, `PlanError`) と、失敗の分類 `FailureKind` で記録 🟡
- 想定外の例外 (認証エラーなど) は握りつぶさず上に出す 🟡

### Style / Documentation
- 純粋ロジックは入力を変更せず、乱数・時計を使わない (seed を引数に取る) 🟡
- docstring・コメントは日本語。`【機能概要】` と信号機 (🔵🟡🔴) を付ける 🔵
- 数値の根拠は `docs/implements/so101-vlm-pickplace/TASK-xxxx/` に記録 🟡
- 定数は `configs/*.yaml` か `scene_spec.py` に置く。XML との一致は `tests/test_scene.py` が照合する 🔵

### Import Style
標準ライブラリ → 外部 (numpy, mujoco) → `so101_vlm.*` の絶対 import。 🟡

### Logging
logging は未使用。スクリプトは `print` で 1 試行 1 行 + 集計を出す。 🟡
